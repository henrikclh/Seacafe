# 魚鳴嘴咖啡 · 四案設計比較

Interactive architectural and landscape study for the coastal café.

- Four switchable 3D options, including Hugo Option 04 updated2 / v4d roof.
- Orbit, zoom, pan, and six preset views per option.
- Desktop and mobile layouts.
- Static site; all model assets and viewer dependencies are hosted in this repository.

GitHub Pages publishes the root of the main branch. No build or server is required.

Three.js and its bundled Draco decoder are included under vendor; retain their license notices. Architectural project content is supplied for this design review.
